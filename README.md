## How to run ? 
 
<details>
<summary><strong>Development</strong></summary>
<br>
    
> Build & run dev env
```bash
$ make dev-up
```
    
> Stop dev env
```bash
$ make dev-down
```

> View logs
```bash
$ make dev-logs
```

</details>

---

<details>
<summary><strong>Production</strong></summary>

> Build & run production containers 
```bash
$ make up
```
    
> Stop the production containers 
```bash
$ make down
```

> View production logs
```bash
$ make logs
```

<br>
</details>
